# Signup Form
A simple webpage as part of The Odin Project curriculum set to practice form validation.
It's a 2-column page, one column having back-ground image and the other the form description plus the form itself.

# Installation
1. Navigate to your repos/ folder e.g
```bash
cd ~/repos/
```
2. Clone the project repo to your local environment
```bash
git clone "git@github.com:mwalania/signup_form.git"
```
3. Open VS Code 
```bash
code .
```

4. Create necessary files e.g
```bash
touch index.html style.css 
```
